This mod REMOVES ALL PARTICLES in Minecraft 1.21.11 (Fabric). Client-side only.

EASIEST WAY (Windows):
1. Unzip this folder.
2. Double-click build.bat
   - If it installs Java or Gradle, close the window and double-click it again.
3. Your .jar appears in the MY-MOD-JAR folder.
4. Put it in .minecraft\mods (you need Fabric Loader for 1.21.11).

NO-INSTALL WAY (GitHub builds it for you):
1. Make a free repo on github.com and upload everything here (including the hidden .github folder).
2. Open the Actions tab, wait for the green check, download "noparticles-mod".
